- Kiosco 24/7 — API RESTful con Spring Boot
API RESTful para la gestión de un kiosco, desarrollada con Spring Boot siguiendo la arquitectura en capas por convención (Controller, Service, Repository, Model, DTO). Incluye gestión de productos y categorías con relaciones entre entidades, validaciones de entrada, manejo global de excepciones con mensajes descriptivos y códigos HTTP correctos. Persistencia con Spring Data JPA y MySQL, con credenciales protegidas mediante variables de entorno. Endpoints probados con Postman.
Tecnologías: Java 21 · Spring Boot · Spring Data JPA · Hibernate · MySQL · Lombok · Maven

- Kiosk 24/7 — RESTful API with Spring Boot
RESTful API for kiosk management built with Spring Boot, following the standard layered architecture (Controller, Service, Repository, Model, DTO). Features full CRUD for products and categories with entity relationships, input validations, global exception handling with descriptive messages and proper HTTP status codes. Data persistence via Spring Data JPA and MySQL, with credentials secured through environment variables. All endpoints tested with Postman.
Tech stack: Java 21 · Spring Boot · Spring Data JPA · Hibernate · MySQL · Lombok · Maven
